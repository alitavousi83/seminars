# AI Seminar — فایل ارائه

- `AI-Seminar.pptx` — نسخه‌ی اصلی (۶۸ اسلاید، ۱۶:۹)
- `AI-Seminar.pdf` — نسخه‌ی PDF برای اشتراک‌گذاری سریع
- `fonts/` — فونت Vazirmatn برای نصب روی سیستمی که قرار است ارائه از آن پخش شود

## قبل از ارائه

1. روی کامپیوتر مقصد، فونت‌های داخل پوشه‌ی `fonts` را نصب کنید (انتخاب همه → کلیک راست → Install).
2. فایل PPTX را باز کنید و یک‌بار Slide Show را اجرا کنید تا انیمیشن‌ها و ترنزیشن‌ها بررسی شوند.
3. یادداشت‌های سخنران در بخش Notes هر اسلاید قرار دارد (View → Notes Page).
